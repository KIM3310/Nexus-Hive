# Fictional Discovery Narrative: Financial Services

This document is a fictional composite for discovery conversations. It is not a
customer reference, production deployment record, benchmark, or outcome claim.

## Scenario

A financial-services analytics team wants governed natural-language access to
warehouse data without bypassing policy review, semantic definitions, or audit
logging.

## Questions To Validate

- Which warehouse connectors and identity controls are required before any
  private data is used?
- Which query patterns should be allowed, reviewed, or denied?
- What audit export format would satisfy the buyer's internal review process?
- Which public demo behaviors map to the buyer's real approval workflow, and
  which require custom implementation?

## Readiness Sprint Fit

The paid path is a quoted private AI readiness sprint. A scoped engagement
should produce a connector readiness map, policy boundary notes, audit-export
requirements, deployment options, and a go or no-go roadmap. Do not present this
scenario as evidence of live customers, production traffic, cost savings, or
guaranteed adoption results.
